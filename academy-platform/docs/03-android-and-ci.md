# تطبيق Android والبناء التلقائي (المرحلة 3)

> **حالة التحقق:** الكود مكتوب لكنه **لم يُترجم ولم يُبنَ بعد**، لأن بيئتي لا تصلها أدوات Android. أول بناء على GitHub هو أول اختبار حقيقي، ومتوقَّع أن يظهر فيه خطأ أو اثنان يُصلَحان.

## ما يحتويه التطبيق الآن

- شاشات: بداية، تسجيل دخول، إنشاء حساب طالب، الرئيسية (الاسم، الدور، الجهاز المرتبط، تسجيل الخروج).
- واجهة عربية RTL بالكامل ووضع ليلي/نهاري يتبع النظام.
- تخزين التوكنات مشفّرًا بـ Android Keystore (`EncryptedSharedPreferences`)، ولا تُخزَّن كلمة المرور.
- تجديد تلقائي للتوكن عند انتهائه، وخروج تلقائي إذا أُلغيت الجلسة أو الجهاز.
- رسائل أخطاء عربية واضحة (لا إنترنت، جهاز مرتبط بحساب آخر، قفل مؤقت، ...).
- `FLAG_SECURE` يعمل في نسخة الإصدار فقط، وتعطيله في نسخة التجربة (debug) ليتسنى لك تصوير الشاشة. لا يمنع التصوير بكاميرا خارجية.
- حقل "عنوان الخادم" ظاهر للتجربة، وسيُخفى في النسخة النهائية.

الكورسات والمشغّل والامتحانات تأتي في المراحل التالية، ولا توجد أزرار شكلية لها.

## البناء التلقائي (مجاني)

الملف `ci/build.yml` يعمل على GitHub Actions عند كل رفع، ويقوم بـ:

1. تشغيل اختبارات الخادم الـ 17 على PostgreSQL حقيقي.
2. تشغيل اختبارات وحدة التطبيق وبناء `app-debug.apk`.

لتفعيله، من الطرفية في Codespaces:

```bash
bash academy-platform/setup-ci.sh
```

ثم افتح المستودع على GitHub ← تبويب **Actions** ← آخر تشغيل ← في الأسفل **Artifacts** ← `academy-debug-apk`.

## تشغيل الخادم للتجربة من Codespaces

```bash
cd academy-platform
docker compose -f infra/docker-compose.yml up -d postgres
cd server
set -a; . ../.env; set +a
npm run migrate && npm run seed
DEV_EXPOSE_RESET_TOKEN=true npm run start:dev
```

ثم من تبويب **Ports** (المنافذ) اجعل المنفذ 3000 **Public** وانسخ عنوانه (يبدأ بـ `https://`) وألصقه في حقل عنوان الخادم في التطبيق.

حسابات `seed` المحلية: الهواتف `01000000001` إلى `01000000004` (الطالب هو `01000000004`)، وكلمة المرور التجريبية الموجودة في `scripts/seed.js`.

## قيود معروفة

- Codespaces يتوقف بعد فترة خمول، فيتوقف الخادم، وتشغّله من جديد عند التجربة.
- المنفذ العام يمكن لأي شخص يعرف عنوانه الوصول إليه، فلا تترك بيانات حقيقية عليه، وأغلقه (Private) بعد التجربة.
- النسخة الموقّعة للنشر (release) وأيقونة التطبيق وحماية Play Integrity لم تُنفّذ بعد.
